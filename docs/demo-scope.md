本文定义首版演示的功能范围、服务边界和验收要求。默认保留完整演示，派生项目的体验路径、扩展教程和裁剪方法见 [模块指南](./demo-modules.md)。

精简模式只影响展示与命令过滤。桌面与浏览器共用 React 源码，浏览器中的原生能力入口说明环境限制，实际调用由门面检查。

## 服务与依赖

原生能力使用 Tauri 官方插件，文件授权、数据事务、任务调度和退出协商由应用服务维护。目录扫描与哈希使用 walkdir / sha2，数据库使用 rusqlite，凭据使用系统 keyring。WebSocket 使用标准 API，门面与生产 CSP 限制 WSS 端点。

前端按页面懒加载 TanStack Query / Table / Virtual、React Hook Form / Zod、react-markdown / remark-gfm 和 Recharts，基础组件复用 `src/components/ui/`。依赖版本、许可证及加载边界见 [依赖与加载](./demo-modules.md#依赖与加载)。

Rust 命令与 DTO 由 `bindings.rs` 注册并生成 TypeScript 契约；前端系统能力只通过 `src/lib/tauri.ts` 使用。模块职责和持久化边界见 [架构说明](./architecture.md)。

## 契约与失败路径

- 文件路径由原生选择或拖入授权，前端持有受控标识；读取限制大小与编码，写入原子替换并检测外部修改。
- 任务有稳定 ID、快照与终态，使用有界队列和合作取消；停止等待不代表回滚，重启后的中断任务可显式重试。
- 设置与数据库校验数据 schema，支持事务迁移和未来版本拒写；备份先验证再恢复，恢复前保留安全备份与原件。
- 退出前收集各窗口脏状态与在途工作，保存失败或取消时保留窗口；原生退出、托盘、更新和重启共用协调入口。
- HTTP / WebSocket 仅访问指定 HTTPS / WSS 端点，fixture 明确标注为本地演示；子进程仅执行内置固定 worker 协议。
- 权限限于实际使用的窗口、系统能力和演示端点，边界验证见 [安全规范](./security.md)。

## 验收要求

按 [测试规范](./testing.md) 验证领域规则、失败保留、类型与绑定、工程脚本、生产构建、浏览器交互和真实桌面场景。数据往返覆盖超过一页的完整记录、回收站与窗口草稿；恢复和多窗口场景同时验证冲突、取消及重启。

浏览器检查覆盖项目子路径、刷新、偏好恢复、fixture、键盘、无障碍、中英 / 明暗 / 窄屏与虚拟表格。性能采样注明浏览器、窗口、数据量及构建配置，原始记录放在忽略的 `artifacts/` 中，不作为跨设备性能承诺。

正式安装、卸载、系统授权、深链 / 文件关联、签名、公证和真实更新须使用目标平台最终安装包验收。CI 与隔离 debug E2E 的结果不替代这些检查。外部服务、生产认证和签名更新需要维护者配置，具体要求见 [发布检查清单](./build-release.md#发布检查清单)。
