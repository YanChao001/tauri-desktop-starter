# 设备会话与有限字节流

本文维护设备领域的当前模块边界。演进范围见 [实施计划](./plans/device-workbench-foundation.md)，长期取舍见 [ADR 0024](./adr/0024-device-session-capture-boundaries.md)。当前只提供虚拟输入、只读游标与发送仲裁，不提供真实串口或插件设备授权；记录与回放在后续里程碑接入。

## 模块与责任

| 模块                              | 责任                                                      |
| --------------------------------- | --------------------------------------------------------- |
| `src-tauri/src/device/model.rs`   | 会话 ID、连接事件、方向、二进制字节、偏移、缺口与共享校验 |
| `src-tauri/src/device/session.rs` | 虚拟会话生命周期、连接代次、有界发送队列、显式推进及结算  |
| `src-tauri/src/device/stream.rs`  | 单份有限历史、独立只读游标、受限批次与淘汰缺口            |

设备模块不依赖文件、Tauri、React 或插件页面。当前仍与桌面应用在同一 Rust crate 中编译，不表示已经实现轻量独立运行时分发。没有新增自动后台线程、桌面 state、IPC、插件服务或 capability。

内部 API 供可信 Rust 调用方使用，不是用户授权。未来设备 API 对外开放前，须完成资源选择、权限、所有者、撤权和退出协商，不能直接把可用 Rust 方法全部注册为 IPC。原生调用即使复用同一领域模块，也必须经过资源身份和授权边界。

## 会话、连接与显示

- `SessionId` 表示业务会话；每次连接的 token 绑定该会话与新的 epoch，不能把旧 token 自动转换成当前连接。
- 断开／重连后旧发送、晚到输入和推进全部拒绝。事件序号、Rx 与 Tx 字节偏移在会话内继续递增，不因重连清零。
- 时间戳是会话开始后的主机观察单调微秒，不是逐字节线路时间或跨设备同步保证。
- 读取者只有只读游标；销毁或重建读取者不关闭连接。关闭会话后可排空剩余历史，排空后才报告 EOF；未关闭的空批次不表示结束。
- 虚拟发送先入有限 FIFO 队列，由显式 `step_virtual` 推进为模拟 TX 和回显 RX。入队不表示发送完成，模拟完成不表示真实设备 ACK。
- 断开／关闭／shutdown 不等待普通发送队列腾出位置，未执行 ticket 结算取消；连接重建不重发旧队列。最后一个引擎释放时，即使读取者仍保留历史，残留未执行 ticket 也结算取消；该释放不伪造关闭事件，正式结束仍应显式 shutdown，使读取者获得关闭事件与 EOF。

## 有限历史与批次

历史同时限制项数和字节。落后的读取者取得半开序号区间 `[from_sequence, to_sequence)` 的 `Gap`，再读取现存事件。它只证明会话历史已经淘汰这些事件，不推断物理设备丢了多少字节。读取批次的项数包括 Gap；下一帧连整个字节预算都容纳不了时明确报错，整个游标不推进，不无休止返回空批次。仅当本批剩余额度不足时返回已读前缀，下次再读完整帧。

单个字节事件上限在 [公共模型](../src-tauri/src/device/model.rs) 定义；内存、队列及批次限额在 [设备实现](../src-tauri/src/device/) 定义。额度保护宿主持有的历史、队列与单批数据，不覆盖调用方无限保存已返回批次的行为。

输入和状态转换先校验再提交，非法数据或计数溢出不产生半个 TX／RX，不推进历史。正常调用只持当前会话的短锁；不同会话不靠单一全局串行队列执行。shutdown 明确关闭并结算，之后不再创建会话。

## 验证与后续

就近测试覆盖独立游标、历史淘汰、队列与旧 token、关闭排空、最后引擎销毁结算和容量回收；从仓库根目录先构建 `dist/`，再运行：

```bash
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml --locked --lib device::
```

记录回放与可操作无头 CLI 按 [M3／M4](./plans/device-workbench-foundation.md#里程碑与集成顺序) 集成；此时不提前声明文件格式或命令已经可用。没有真实 UART、设备枚举、控制线、原生推送、界面面板、持久工作区或物理重连，也不保证应用退出期间持续采集。浏览器 demo 保持原有环境边界，不伪造设备调用成功。
