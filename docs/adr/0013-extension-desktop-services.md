## 背景与选择

内网聊天需要长连接与监听，壁纸工具需要访问宿主图库和设置。将它们伪装为每次重新创建实例的 Wasm 效果会造成轮询、连接与资源生命周期混乱；放开网页任意 IPC、路径和网络则绕过已有权限边界。

保留 Wasm 作为业务与工具入口，高频计算、游戏绘制和表单交互在隔离 UI 内完成。增加有限的 `lan` 与 `wallpaper` 服务，按明确动作访问本机能力，不提供任意服务注册、命令、路径或 Shell。界面 SDK 默认提供与宿主一致的基础样式，作者仍可覆盖。

## 权限与数据归属

新增独立能力 `messaging:lan` 与 `wallpapers:manage`，插件可按功能门槛声明为必需或可选。服务调用由宿主附加已安装身份、哈希、代次和窗口，Rust 复核启用、授权与生命周期；不采纳插件自述身份。服务执行与包替换、撤权、卸载使用读写门闩协商，已开始的调用完成前不提前声明撤权完成，关闭不冒充副作用回滚。服务租约纳入关闭、退出、重启与更新的等待，最终写入前在窗口锁下复核生命周期；窗口重新打开使用新代次的资源归属，旧窗口的异步清理不会关闭新窗口的连接。

LAN 只接受私有网段或环回 IP，显式启动监听或连接，不调整系统防火墙。首版为有限文本聊天，明确明文及无账户认证边界，不借用 QQ / 微信服务。联系人、消息历史由独立服务按插件保存；关闭最后一个使用窗口、撤权或退出时停止自己拥有的连接，保留历史，损坏与未来存档拒写。

壁纸服务复用宿主图库与设置的原子写入和 revision，不另建背景偏好。远程来源限定 Wikimedia Commons 官方 API，逐次核验明确的公共领域 / CC0 许可、图片地址、重定向、字节与像素额度；下载原图须用户选择路径，图库导入按现有额度重绘，缩略图不冒充原图。新增直接依赖 image 0.25.10，复用已锁版本，启用 JPEG / PNG / WebP 编解码；许可 MIT / Apache-2.0，影响三平台原生包体与构建，禁止无界图片解码。

固定来源服务默认沿用现有 reqwest 的系统代理和 `NO_PROXY`，也提供明确直连模式。真正直连来源时，所有 DNS 地址必须为公网，并将同一组已验证地址交给连接器，拒绝 Fake-IP。系统选出的代理服务器可以位于本机或内网，远端目标由代理解析时无法核验其最终 IP；此路径依靠固定 HTTPS 来源、精确 host / path、正常 TLS 证书验证、禁止跳转与内容预算。插件不能指定代理地址或关闭 TLS；通用扩展 HTTP broker 保持原有策略。

## 兼容、失败与验证

开发阶段扩展协议增加可选能力和服务入口，旧包不自动获得新授权。旧市场应用从收录与源码移除，不删除用户已安装包、私有数据或历史。新市场和宿主必须配套发布；不以刷新前端代替更新 Rust。

验证分别覆盖：原生授权与撤权并发、窗口关闭和连接资源回收；双端真实环回通信与坏帧；图片来源、大小、解码和图库 CAS；数学解析与数值算法；真实 Wasm 构建和手写用例；无头 UI 的主题、语言、键盘、音效启动与暂停、图形交互、布局和短任务稳定性。真实多机 LAN、防火墙提示、WebView 和正式安装版单独记录，不用浏览器替身声称通过。
