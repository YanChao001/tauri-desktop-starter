# 14. 用必应图片搜索提供关键词壁纸结果

- 状态：被 0015 取代

- 日期：2026-10-26
- 决策者：维护者要求实施，编码智能体实现自审与分层验证
- 相关：[壁纸服务](../extensions.md#壁纸图库与图片搜索)、[0013](./0013-extension-desktop-services.md)

## 背景与选择

Commons 的许可过滤与站内检索不能满足用户按普通关键词寻找壁纸的需求。维护者明确要求使用必应图片结果，个人使用不按许可筛选。[微软已于 2025-08-11 退役 Bing Search APIs](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement)，不以已退役 API 或未配置的商业服务作为实现前提。

保留 Commons 能维持原有许可范围，但无法解决本次关键词相关性问题；让插件提交任意图片 URL 则扩大成通用下载入口。选择由原生服务读取必应图片搜索网页，有限解析结果元数据、必应缩略图和第三方 HTTPS 原图地址，复用已锁定依赖，不再自动限定图片许可。界面明确来源和未筛选许可，不声明搜索结果可自由使用。

## 权限与安全边界

`wallpapers:manage` 的可访问内容扩展为必应搜索及搜索结果中的第三方图片来源，安装审阅文案、插件清单和文档同步说明。普通 HTTP broker 的精确 origin 权限保持独立；插件不能注册来源或提交下载 URL。

宿主用有界、带 TTL 的内存缓存保存已解析结果，返回绑定插件安装身份与原生窗口的不透明 `resultId`。后续操作只从当前身份的缓存解析 URL，过期或身份变化要求重新搜索。保留 HTTPS、正常证书、DNS / SSRF、重定向拒绝、MIME、真实解码、字节与像素预算，不能为提高下载成功率关闭这些边界。系统 / 直连策略及代理解析限制由[当前服务说明](../extensions.md#壁纸图库与图片搜索)维护。

原图仍经检查后由系统对话框另存，图库导入仍重绘压缩并服从原有配额；应用背景通过既有设置 revision CAS 保存。现有服务门闩、活动租约和窗口关闭前最终提交检查继续覆盖这些操作。

## 兼容、后果与验证

默认搜索改用必应；旧 `pageId` 预览、导入和下载继续使用 Commons 兼容路径及原有许可复核。新增结果缓存只在内存中存在，不改变图库、设置、注册表或会话存档 schema，无持久数据迁移；重启后需重新搜索。上线必须重编并重启配套 Rust 宿主及重建插件包，不能只刷新前端或修改版本字符串。

网页解析没有稳定 API 契约，页面改版、地区差异、验证码或限流会导致搜索失败；第三方原图也可能过期、禁止访问、仅提供 HTTP、跳转或超出图片额度。失败需明确反馈并保留已有搜索与图库，不伪造成功，也不自动改用不相关的 Commons 结果。

离线验证覆盖 HTML 解析、结果来源与身份隔离、TTL、URL / SSRF / DNS、重定向、格式与解码额度、旧 `pageId` 兼容、原图与压缩导入区别；真实原生搜索和下载需独立记录网络模式与来源，系统另存、WebView 和正式安装版仍单独验收。

## 复查条件

必应网页结构或访问政策使解析持续不可用，或项目需要稳定服务承诺、更多图片格式、重定向和批量下载时，重新评估有正式契约的搜索 provider 与授权范围，不能通过放宽任意 URL 或内网访问兜底。
