# 9. 为扩展提供页面与独立窗口

- 状态：已采纳
- 日期：2026-10-24
- 决策者：仓库维护者（需求确认）、编码智能体（实现自审）
- 相关：[扩展指南](../extensions.md)、[0008](./0008-extension-app-views.md)

## 背景与影响

模态应用遮挡主界面，简单按钮示例难以展示 Extism 的数据能力，示例画廊与已安装列表重复。维护者要求扩展能注册侧栏，也能像小应用一样独立运行，并允许精简重构。

本次影响路由、命令、安装记录、视图 IPC 和窗口生命周期。沿用 Extism、宿主绘制与原有授权 broker，不引入第二个运行时或 UI 框架。单维护者按设计门槛进行自审，未虚构独立审批。

## 备选方案

| 方案                 | 优点                           | 代价                                   |
| -------------------- | ------------------------------ | -------------------------------------- |
| 扩大模态框           | 修改少                         | 仍阻断主窗口，无法并排使用             |
| 插件提供任意网页     | 自由布局                       | 新增执行与系统权限边界、独立前端打包链 |
| 声明式页面与系统窗口 | 复用主题、路由、无障碍和运行时 | 控件能力由宿主协议限定                 |

## 决策

选择声明式页面与系统窗口，取代 0008 中固定模态承载及视图禁止数据权限的限制；其余运行时约束继续有效。

- 清单可声明侧栏和独立窗口入口；省略时仍可在扩展中心打开普通页面。路由只接受已安装且启用的命令，动态导航不绕过权限或精简模式。
- 独立窗口由 Rust 创建，仅加载宿主本地页面，复用主窗口皮肤与自绘标题栏，保留最小化、最大化、关闭与缩放；平台装饰继承主窗口配置，macOS 保留 Overlay 红绿灯。同一扩展命令重复打开聚焦既有窗口。关闭遵循未保存工作协商，不套用主窗口关闭到托盘规则。禁用、卸载或升级后停止旧实例并撤销入口。
- 页面与窗口使用相同有界视图协议。增加常用表单、指标、表格、Markdown 与棋盘按钮布局；插件不返回可执行 HTML、远程页面或宿主 JS。每次执行仍是全新 Wasm 实例。
- 视图允许声明既有文本、文件与 HTTPS 权限。数据只在用户明确“发送所选数据”时通过同一个 broker 传入，普通按钮不重复读取文件或发送网络请求。实例状态和导出沿用未保存工作约定。
- 内置扩展实验室仅安装一次，初始禁用且不授予权限，直接出现在已安装列表；卸载后不自动重装。手动安装同 ID、已存在的包、未来或损坏存档不得被默认资源覆盖。

## 兼容与失败恢复

清单与视图增加可选字段，旧 API 1 包继续运行。注册表增加可选的默认包初始化标记，保持 schema 2；先校验原存档，再写入新包和原子更新记录。初始化失败保留原记录，稍后重试；安装上限达到时不强制插入。已有计算器与游戏安装记录保持有效，可由用户自行卸载。

全局独占运行租约、取消、隔离恢复与关闭等待保持不变。窗口不是 Wasm 状态共享通道；不同窗口各自拥有会话。平台原生窗口操作使用既有 Tauri 能力，不扩大插件文件路径、网络域名或进程能力。

自绘标题栏使用扩展窗口限定的拖动权限；皮肤与主题继续由既有设置同步提供，不新增存档或 IPC 格式。渲染失败仍保留宿主错误边界与关闭协商。

## 验收与代价

验证默认安装幂等、卸载不复活、同 ID 不覆盖、数据权限和输入上限、真实 Wasm 分析及解谜规则、动态导航撤销、正常页面不产生遮罩、独立窗口路由与关闭协商。前端采用无头交互、布局与无障碍检查；原生窗口按钮及正式安装升级需在安排的前台或独立环境验收，不能用浏览器 mock 代替。

宿主需要维护有限控件协议和更多窗口生命周期。尚不提供任意 Web UI、扩展市场或无限系统权限。出现必须自绘画布、实时媒体或远程内容的实际需求时，再复查第三方内容隔离方案。
