# 4. 将多图图库与当前背景设置分开保存

- 状态：已采纳
- 日期：2026-10-22
- 相关：[ADR 0003](./0003-local-background-image.md)、[设置架构](../architecture.md#状态管理与设置迁移)

## 问题与方案

用户需要多选导入、切换、重命名和删除壁纸。将全部图片放入设置会突破现有 128KiB 边界，并使每次偏好同步携带整套图库；保存原图及文件路径则引入路径授权、解码和资源回收问题。本次沿用本机重编码的有界图片，以独立图库保存优化副本，当前背景继续使用 schema 3 的自包含图片快照。

桌面图库由 Rust 服务负责，保存在应用数据目录的 `wallpapers.json`，单实例内串行执行增删改并复用原子写入。浏览器演示使用独立 IndexedDB 的读写事务。每张图片沿用 96KiB data URL 上限，最多 24 张；SHA-256 内容 ID 用于去重，不接受文件路径、远端 URL 或 SVG。图库版本独立于设置，未知版本或损坏内容拒绝写入。接口及 DTO 由 Rust 生成，不新增运行依赖。

## 兼容与失败路径

首次初始化图库时纳入已有自定义背景；设置格式及其 revision 冲突协议不变。旧版本仍能显示当前壁纸，不改写独立图库。选中的图片在设置中保留完整副本，图库删除、加载失败或回退不会产生悬空资源引用。重置外观取消当前壁纸但保留图库；删除图库条目不修改原始图片。

批量导入逐张落盘，失败项显示文件名及原因，已成功项保留；切换皮肤或卸载后不让晚到结果改变当前背景。删除或重命名仅在持久化成功后更新列表，跨窗口事件通知重新读取图库，当前选择仍复用设置同步。恢复隔离模式将图库放到隔离临时目录，不触碰生产图库。现有数据库备份范围不扩展到图库；当前背景仍随原有设置存档保留。

## 验证与边界

自审范围包括设置与图库的职责、Rust 输入校验、原子失败保护、并发操作和浏览器事务。验证覆盖旧图片纳入、去重、容量、损坏 / 未来格式拒写、重启、多窗口通知、导入部分失败与晚到结果、切换 / 重命名 / 删除，以及明暗与窄屏布局。本机采用无头浏览器和 Rust 测试，真实原生多窗口与安装器高 DPI 验收留给独立环境或明确安排的前台时段。

本次不保存原图、动画或跨设备同步。需要这些能力或超过 24 张图库时，重新评估独立图片文件和缩略图缓存，不能继续放宽设置体积限制。
