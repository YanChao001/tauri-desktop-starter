# 6. 通过独立进程接入可安装原生扩展

- 状态：被 0007 取代
- 日期：2026-10-23
- 决策依据：用户明确选择允许 Rust / 系统命令以及按需开放文件、网络能力的原生方案
- 相关：[原生扩展](../extensions.md)、[架构说明](../architecture.md)、[安全规范](../security.md)

本文保留未发布原生原型的历史决策；当前实现见 [ADR 0007](./0007-extism-extensions.md)。

## 背景与影响

数据工作流、冲突比较、可下载样例和内容搜索可以沿用现有领域。可安装扩展则引入外部可执行文件、独立存档和进程生命周期，影响 IPC、数据授权、退出 / 重启及更新安装。用户要求原生能力，因此仅提供声明式模板或纯 JavaScript 文本处理不能满足目标。

## 备选方案

| 方案                                | 收益                                                  | 代价                                                     |
| ----------------------------------- | ----------------------------------------------------- | -------------------------------------------------------- |
| 声明式包或受限 JavaScript           | 更小的系统能力范围                                    | 无法直接运行用户选择的 Rust 工具和系统命令               |
| 原生动态库加载到宿主                | 调用直接                                              | ABI、崩溃传播与内存安全边界复杂，库故障直接影响宿主      |
| 独立可执行文件与标准输入 / 输出协议 | 不依赖 Rust ABI，可管理超时和进程树，也可接入现有 CLI | 仍拥有用户系统权限；需逐平台构建、确认信任并处理进程清理 |

## 决策与兼容

采用本地 JSON 包携带平台可执行文件，独立进程执行；共享的小型 Rust SDK 只维护 JSON 契约，不依赖 Tauri。首版同时支持 JSON 请求 / 响应和标准命令行文本输出。参数固定在经过审阅的 manifest 中，用户输入只走 stdin，不拼接 shell 字符串。包、API、平台和数字版本在 Rust 边界校验；不支持动态库、远程安装、自动启动或常驻扩展。

安装不执行程序，默认禁用。启用要求明确确认原生信任及全部声明用途。升级只接受更高版本，并清除旧授权、禁用新版本、取消旧运行。包中的作者未经签名认证；SHA-256 标识可执行内容，不提供发布者认证。

权限清单是宿主数据交付和用户知情边界，不是操作系统沙箱。原生程序可以自行调用系统命令、访问文件或联网。宿主 broker 只提供本次主动选择的文本文件内容及声明白名单的有界 HTTPS 响应，不传原生路径、应用存储、凭据或整个父进程环境。进程树管理用于资源清理，不承诺防止恶意本机程序逃逸。

扩展注册表独立于设置和 SQLite，使用版本化 JSON、revision 条件写入和原子替换；不迁移原有用户数据，也不纳入笔记备份。未来版本或损坏注册表拒写，原件保留。启动恢复隔离时禁止安装与运行。正常退出 / 重启等待实际运行结束；更新安装期间暂停新运行并持有占用，安装失败后释放暂停。取消与卸载不冒充系统副作用回滚。

## 依赖与代价

不引入脚本引擎或额外下载器。复用锁文件中的 serde、SHA-256、base64、tempfile 和 HTTP 插件已有的 reqwest；本地 `starter-extension-api` 使用项目 MIT 许可。Unix 直接声明已有传递依赖 libc（MIT OR Apache-2.0），Windows 为已有 windows-sys（MIT OR Apache-2.0）增加 Job、线程 I/O 和 OEM 解码 API feature。它们由目标平台条件编译，不增加 WebView capability 或 CSP 来源。锁文件保留原版本，仅新增本地 SDK 条目。构建体积和平台运行结果以本次交付验证为准，不以源码规模推断。

## 验证与复查

服务测试覆盖安装默认禁用、信任与授权、revision、重启读取、升级重置、执行文件改动、未来存档保护、恢复隔离、独占租约、取消 / 超时与卸载清理。独立 Rust 示例使用真实打包、安装和无头 CLI 协议往返验证；前端测试覆盖确认流程、失败保留、取消导出、晚到订阅及停止期间占用。浏览器仅验证限制说明及共享交互。真实窗口、正式安装 / 升级以及 Windows 之外的平台按测试规范单独验收。

若需要不受信任的扩展市场、发行者签名、后台服务、任意 broker 域名、写文件 API 或跨用户隔离，须重新评估系统沙箱、身份验证、协议与权限模型，不能只增加权限字符串。
