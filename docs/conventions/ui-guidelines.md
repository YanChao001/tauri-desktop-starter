# 界面规范

界面复用语义 token 和现有组件；下面维护共同绘制、交互与阅读约定。按 [日常验证范围](../testing.md#日常验证范围) 检查受影响的状态，纯样式调整以界面结果为准。

## 设计基础

- 组件与基础样式由 [components.json](../../components.json)、[index.css](../../src/index.css) 组织；`styles/shadcn.css` 保留上游原文，升级见文件头。
- 颜色、字体、圆角与尺寸消费 CSS 变量和 Tailwind 刻度；平台窗口控件的固定尺寸集中在外壳。
- `next-themes` 使用 `.dark` class；组件保留用户配色，内置背景消费皮肤环境色，用户照片保留原色。
- 页面共用 `styles/showcase.css`，场景维护局部样式；Motion 与 CSS 动画共同遵循 [动效](#动效)。

## 宿主与插件的共同外观

内置插件与市场插件的普通控件、分组和阅读区复用宿主的字体、尺寸、材质及交互状态，嵌入页面和独立窗口均适用；插件负责业务布局、内容密度与专用绘制。

[surface-tokens.css](../../src/styles/surface-tokens.css) 维护材质参数，[control-styles.css](../../src/styles/control-styles.css) 维护通用绘制规则；宿主直接消费，隔离插件通过 SDK 接收相同原文与运行时变量。共同样式修改放在这两处，新增共享文件接入现有装配与检查。注入范围、设置同步及 Shadow DOM 接入见 [SDK 默认外观](../../sdk/README.md#默认外观与动效)。

游戏、图表或专用操作区可使用独立视觉设计，在对应模块或插件说明中写明用途和范围；整套游戏设计可包含菜单、HUD 与配套设置。普通控件继续复用共同规则，专用区域也保留可读性、键盘操作、主题与减少动效支持。

共同样式变更对照实际宿主组件与真实注入的插件控件，按影响选择主题、外观参数、控件状态和窗口场景。现有 [无头样式对照](../testing.md#自定义扩展界面) 验证已覆盖规则；作者 CSS 和设计例外结合实际界面检查。

## 外观设置

外观由 `<html>` 的 data 属性驱动，普通组件只消费语义 token。取值、默认值与迁移以 [设置模型](../../src/lib/settings-model.ts) 为准。

| 属性                                            | 作用                                       |
| ----------------------------------------------- | ------------------------------------------ |
| `data-accent`                                   | 强调色，覆盖主色、焦点环、图表和侧栏强调色 |
| `data-radius`                                   | 圆角，改写 `--radius`                      |
| `data-font` / `data-font-size`                  | 字体和根字号                               |
| `data-background` / `data-background-intensity` | 窗口插画、用户图片及装饰强度               |
| `data-motion`                                   | 全局动画与过渡策略                         |

主题在挂载前恢复首屏偏好，运行时由共用 `ThemeEffects` 与 `use-theme-switch` 提交。原生窗口只接受通过 revision 校验的设置快照，缓存用于后续启动，接收结果不再次回写。主窗口与隔离插件共用同步入口；过渡与降级规则见 [动效](#动效)。

**加一个外观项的顺序**：`lib/settings-model.ts` 加类型、默认值与归一化 →
`applySettings` 写 data 属性 → `index.css` 写对应规则 → 设置页加控件。
改变已有持久化格式时同步处理设置迁移。普通业务组件通过语义 token 绘制；设置页和展厅预设复用现有设置来源，局部预览调色板留在场景 token 内。

主题色由 [accent-colors.ts](../../src/lib/accent-colors.ts) 注册，色块和主题共用配色变量。自定义色在应用弹层中编辑局部草稿，确认后一次提交，取消保留原配色；切换预设保留上次自定义原色。沿用现有颜色归一化与明暗变体，只把不透明 RGB 十六进制值写入设置；取色控件的渐变和色相记忆留在控件内部，普通控件继续消费语义 token。

背景在 `lib/backgrounds.ts` 注册，由 `window-background.tsx` 装配、`skin-artwork.tsx` 加载 [皮肤 SVG](../../resources/skins/README.md)。新增时同步映射、风格标识与中英文文案，画廊从注册表生成；展示名称与持久化 ID 分离。纯色模式隐藏装饰并禁用强度控制。图片导入保留成功项与失败明细，晚到结果不覆盖新选择，取消背景保留收藏。存储与数据保护见 [数据存储](../architecture.md#数据存储)，取舍见 [ADR 0004](../adr/0004-wallpaper-library.md)。

背景透明度档位与默认值以 [backgrounds.ts](../../src/lib/backgrounds.ts) 为准。0% 隐藏皮肤并恢复实体表面，100% 完整显示壁纸，同时保留正文、导航和控件的阅读保护；材质曲线在共同来源维护。纯色、高对比度和缺少模糊能力时使用实体降级。滑条支持拖动、方向键和 Home / End，显示当前百分比、等距刻度与“不透明 / 透明”端点。

窗口尺寸归原生几何状态，不重复存为主题或布局偏好。预设来自应用配置，标明逻辑像素宽高，选择后立即应用并记忆；工作区不足时适配并提示，其他无效预设禁用并说明原因。界面显示实际尺寸，手动拖动无需匹配预设；失败保留状态与重试入口。浏览器禁用原生尺寸操作，不模拟成功。

启动位置作为持久偏好提供“记住上次位置”和“居中”，默认记住位置；选项保存后在下次创建窗口时生效，当前窗口和重复激活的已有窗口保持原位。恢复默认设置会恢复窗口默认尺寸与记住位置策略，确认框说明作用范围。保存失败时保留确认框和错误。

## 主题插画与轻量资源

内置皮肤使用透明线条蒙版，由 `styles/window-skins.css` 按当前主题和强调色着色；绘制与资源约束见 [皮肤资源说明](../../resources/skins/README.md)。

- 背景覆盖标题栏、侧栏和主体；内容 surface 按强度调节，默认档位保留阅读底色，输入控件、弹层和关键错误保持清晰。
- 设置页缩略预览和实际背景复用同一绘制源与居中裁剪方式，避免预览另画一份导致效果不一致。
- 装饰层不响应鼠标、不进入无障碍阅读顺序；不加载远端图像、字体或脚本。
- 明暗主题和强调色共用语义 token；高对比度与强制颜色模式优先恢复实体 surface，移除装饰。
- 内置全窗口装饰保持静态，独立插件窗口使用视频封面。其他窗口的视频壁纸静音循环，沿用活动状态暂停和封面降级；播放与清理遵循 [动效](#动效)。

## 标题栏

“视图 → 全屏沉浸”、命令面板和 F11 共用命令。进入真实全屏后隐藏标题栏、侧栏和面包屑；边缘唤出面板覆盖正文并使用阅读材质，保留滚动位置，焦点、菜单或侧栏调宽期间保持展开。边缘入口兼容键盘与触屏，减少动效时立即切换。全屏切换自动将导航焦点交给正文时不显示正文焦点环；用户用 Tab 进入正文时保留可见焦点与键盘滚动。F11、Esc 和退出按钮恢复布局与侧栏偏好，Esc 优先关闭菜单。原生通过门面、浏览器通过 Fullscreen API 读取实际状态，系统拒绝或外部退出时同步界面。

- 高度 40px（`h-10`），自绘：左侧共用 SVG 图标与菜单，隐藏重复的应用名文字；右侧命令面板、语言、主题切换与窗口按钮；语言入口不依赖菜单栏是否显示。系统窗口标题及图标的无障碍名称仍保留。
- 拖拽区域用 `data-tauri-drag-region`，只加在空白容器上；按钮与菜单不要加。
- 窗口按钮只在 Tauri 原生窗口显示；网页直接从应用标题栏开始，不附加演示标记、宣传栏或下载外壳。
- 浏览器窄屏在同一标题栏内显示页面选择器并收起桌面菜单，选择器复用 `APP_ROUTES`，切换同一组真实页面。原生能力的环境限制在对应页面说明。
- macOS 保留系统红绿灯（`tauri.macos.conf.json`），标题栏左侧留 `pl-[78px]` 并隐藏自绘按钮。
- 平台判断统一走 `lib/platform.ts`，不要在组件里解析 UA。

## 颜色：只用语义 token

| Token                                            | 用在哪                               |
| ------------------------------------------------ | ------------------------------------ |
| `bg-background` / `text-foreground`              | 页面底色与主文字                     |
| `Card` / `.app-surface` / `text-card-foreground` | 随皮肤强度变化的普通卡片与手写面板   |
| `--surface-card-muted`                           | 随皮肤强度变化的次级面板与卡片页脚   |
| `--surface-reading`                              | 代码、日志、诊断与吸顶表头的阅读材质 |
| `--control-background`                           | 输入、次级按钮与一般状态的控件材质   |
| `--surface-state-hover` / `selected`             | 普通交互的悬停与选中底色             |
| `text-muted-foreground`                          | 次要文字，材质中消费受保护的前景色   |
| `bg-primary` / `text-primary-foreground`         | 主按钮、强调元素                     |
| `bg-destructive`                                 | 删除、不可逆操作                     |
| `text-destructive-foreground`                    | 实心警示背景上的文字或图标           |
| `border` / `border-sidebar-border`               | 分隔线                               |
| `bg-sidebar` / `text-sidebar-foreground`         | 侧边栏                               |

```tsx
// 材质与文字随主题和皮肤设置变化
<div className="app-surface text-muted-foreground border" />
```

主体阅读遮罩独立绘制在 `.window-reading-surface`，不放在滚动主体的背景或子树中，避免控件的背景模糊再次合成祖先底色。遮罩和主体共用 `--app-content-inset`，窄屏、全屏与侧栏调宽沿用同一几何规则。

React / Radix 入口通过 `data-slot`、语义角色和稳定的 `ui-*` 类接入共同绘制，普通 HTML 元素也有默认规则；布局 utility 与作者 CSS 保留定制优先级，适用范围见 [共同外观](#宿主与插件的共同外观)。

| `data-surface` | 用途                                          | 绘制规则                                              |
| -------------- | --------------------------------------------- | ----------------------------------------------------- |
| `transparent`  | 布局、同一阅读面板内部的分组、嵌套代码        | 无底色或模糊，文字由上层阅读面保护                    |
| `panel`        | 普通含文卡片、手写业务面板                    | `--surface-card`，保留最低阅读底色，不加整块模糊      |
| `control`      | 输入、次级按钮、kbd、一般输出 / 会话状态      | `--control-background` 与局部模糊                     |
| `popover`      | 菜单、选择列表、搜索结果、通知                | 覆盖阅读材质与局部模糊；对话框使用专用 dialog token   |
| `reading`      | 长代码、日志、诊断、复杂输出、吸顶表头        | 更强的 `--surface-reading` 与语法色，防止滚动正文叠字 |
| `solid`        | 关键错误、恢复失败、平台原生选项              | 稳定实体底色，使用配对的前景色                        |
| `artwork`      | 图片、视频、Canvas / SVG 内容、作品或品牌场景 | 内容专用配色；外部工具栏和说明仍消费上述材质          |

共享 `Card` 与 `.app-surface` 对应 panel，`.app-control-surface`、`.app-overlay-surface`、`.app-reading-surface` 分别对应 control、popover、reading。手写容器声明用途；嵌套在 reading 中的 `CodeBlock` 可用 `data-surface="transparent"` 避免重复叠层。主按钮、勾选、开关、进度和滑块保留实体语义状态。

模态面板与遮罩共用材质参数，页脚和内部列表继承外层材质；主要磨砂由面板承担。原生 `dialog::backdrop` 与宿主遮罩共用规则；已有 `data-slot` 的浮层按其分类绘制，例如具有 dialog 语义的 Popover 仍采用 popover 材质。

输入和普通控件使用 `--input`，容器与分隔线使用 `--border`，卡片与浮层保持单层轻描边；强边界用于焦点、错误和选中状态。折叠区外框与标题共用 `--disclosure-radius`，展开时标题保留顶部圆角。

危险操作按钮和徽标使用共享的轻染底色、危险文字色及悬停 / 聚焦反馈；关键错误按自身语义使用实体表面。

placeholder 与弱说明使用 `--glass-muted-foreground`，链接使用可读前景色，hover / selected 复用共同规则；选中态保留边框、勾选等结构标记。短暂锁定的扩展字段保持文字和底色稳定。新增控件或 slot 接入共同规则，或明确继承 / 内容专用角色；现有覆盖见 [样式检查](../../scripts/ui-style-policy.test.mjs)。

材质变化检查最终合成结果，特别是高透明度、深浅壁纸下的正文和控件；CSS alpha 本身不能说明可读性。模糊限制在局部表面，iframe 不能跨文档模糊宿主壁纸。插件接入见 [SDK 主题与样式](../../sdk/README.md#默认外观与动效)，取舍见 [ADR 0022](../adr/0022-shared-control-materials.md)。

图表、插画和第三方组件的专用颜色集中在所属 token 或绘制规则，检查适用主题与强调色；普通业务界面继续使用语义 token。

多序列图形使用适配明暗主题、可区分的局部调色板，曲线与图例共用取色入口，并保留名称或序号等文字标识；中性强调色不能抹去序列差异。同组操作保持同高，窄屏换行时仍使用一致尺寸。

## 布局常量

标题栏与侧栏使用视口固定定位，根页面不滚动；`main` 和侧栏导航独立滚动，侧栏首尾操作保持可见。两侧共用稳定滚动槽，显隐、菜单和页面切换保持内容宽度与背景构图。外壳祖先保持固定定位的视口包含块，桌面与网页均按标题栏实际高度留出内容空间。

滚动、惯性和边界反馈使用浏览器 / WebView 原生行为。主内容和侧栏共用 `.app-scroll-region` 管理滚动链与减少动效，具体手感由系统、设备和运行时决定。

自定义扩展界面使用占满可用区域的独立内容框，右边缘与主内容区齐平，文档自然排版并承担整页滚动；外壳按实际剩余空间设置内容框高度。文档内部滚动槽、默认内边距、字体与作者布局规则统一见 [SDK 默认外观](../../sdk/README.md#默认外观与动效)，避免外壳、文档和普通业务区块叠出多条整页滚动条。

切换页面路径或有效导览步骤时只重置内容区滚动，保留导航焦点与侧栏位置；同页查询参数变化保留设置定位。偏好与桌面集成共用 `SettingRow`，对齐操作并按容器换行。滚动行为变化再检查长短页面与真实设备手感，自动化滚轮不能证明触控板惯性。

| 区域         | 值                                               | 类名                                                             |
| ------------ | ------------------------------------------------ | ---------------------------------------------------------------- |
| 标题栏高度   | 40px                                             | `h-10`                                                           |
| 页面位置提示 | 随内容滚动，不另设固定标题栏                     | `app-route-context`                                              |
| 侧边栏宽度   | 默认 224px，180–360px；折叠 56px                 | `settings-model.ts` 定义展开范围，`app-sidebar.tsx` 定义折叠宽度 |
| 内容最大宽度 | 1180px                                           | `app-page-content`                                               |
| 内容区内边距 | 顶部 16px，横向 20–24px，底部 24px               | `styles/app-navigation.css`                                      |
| 卡片之间     | 12px                                             | `gap-3`                                                          |
| 页面区块之间 | 业务页 16px，组内通常 8–12px；展示场景按内容留白 | 共用 studio 与场景样式                                           |

窗口默认最小尺寸 880×600（`tauri.conf.json`）；显示器工作区不足时，原生几何适配会临时降低约束。新增页面要在默认最小尺寸下检查，并确保更小工作区中的主要操作仍可通过滚动到达，不要只在最大化时看效果。

侧栏支持指针和键盘调宽；拖动只预览本窗布局，释放或失去捕获后提交，取消则回退；键盘按操作提交。分隔条保留焦点、范围和值语义，双击或 Enter 恢复默认宽度。折叠导航保留名称与 Tooltip，展开时被截断的名称也提供全文提示；仅响应当前项悬停或聚焦，一次一条，布局变化后不残留延迟提示或旧退出动画。宽度、折叠与 demo / minimal 模式复用设置模型持久化。

导航按体验、桌面能力、已安装扩展与系统分组。顶部将首个非空组名与折叠按钮放在稳定行，滚动区不重复首组标题；折叠态保留展开按钮、分组语义、间隔和页面提示。底部提供命令面板及平台快捷键，不堆放品牌、版本脚注或装饰指标。页面呈现主标题，外壳保留轻量上下文。

响应式布局按可用容器宽度换行；检查最小窗口与最宽侧栏组合下的主要操作。

## 命令、搜索与恢复

菜单、命令面板和快捷键共用 `src/commands/` 与 `CommandsProvider`，路由命令从 `routes.tsx` 派生。新增共用操作先注册命令，入口复用显示名、快捷键格式和图标；图标作为装饰隐藏于辅助技术。键盘操作沿用匹配器对输入、IME、重复按键和冲突的处理。

设置搜索复用 `commands/settings-search.ts` 的索引和稳定控件 ID，结果显示在锚定输入框的非模态浮层，保留输入焦点与 IME。选中后清空查询、关闭浮层并定位目标；改控件 ID 时同步索引，检查中英文搜索与焦点。

设置保存成功保持安静，加载 / 保存状态向辅助技术宣告。保存失败由全局右下角 toast 提供重试并保留修改，恢复后撤回，切页保持单一反馈；未来 schema 保留可见拒写说明。浏览器中的原生入口说明能力限制，实际调用由门面检查。

设置按外观、窗口、更新及可折叠的关于与资源组织；隐藏次要信息仍须支持搜索定位，精简模式导览应匹配保留能力。同级字段复用 `SettingLabel` / `SettingRow` 对齐图标、文字与说明；图标使用同尺寸和语义颜色，无图标时不留空位，不在标题和选项重复装饰。

路由渲染失败由局部边界保留外壳与恢复入口，外壳或根 Provider 失败由最外层边界兜底；事件和请求错误由调用方处理，页面数据错误留在所属数据区。

## 字号层级

下表以默认根字号为基准，实际尺寸随外观设置缩放；布局变化时检查大字号下的可读性与溢出。

| 层级       | 字号    | 类名                            |
| ---------- | ------- | ------------------------------- |
| 页面大标题 | 24px    | `text-2xl`                      |
| 区块标题   | 16px    | `text-base`                     |
| 卡片标题   | 14px    | `text-sm font-medium`           |
| 正文       | 14px    | `text-sm`                       |
| 辅助说明   | 12px    | `text-xs text-muted-foreground` |
| 代码       | 12–13px | `font-mono text-xs`             |

业务页以标题、正文、辅助说明组织层级，展厅标题可随容器放大；应用名和面包屑已提供的上下文无需重复装饰。正文与关键导航保持可读，刻度等小字结合实际字号检查。

普通状态、错误说明与操作反馈继承当前应用字体；等宽字体用于代码、表达式或需要按列阅读的原始数据，不将整个扩展状态区统一设置为等宽。

## 组件选择顺序

先查找 `src/components/ui/` 和已有项目组件，能表达当前语义时直接复用或组合。缺少组件时可用 `pnpm dlx shadcn@latest add <name>` 引入上游控件，或在 `src/components/<domain>/` 自建；继续复用 token、键盘规则和焦点管理，依赖取舍见 [开发指南](../development.md#新增依赖的评审标准)。

有共同目的的一组设置、表单字段或操作参数，优先使用原生 `fieldset` 和首个直接子元素 `legend`，让短组标题嵌入边框。共享规则提供四边一致的 `0.75rem` 内边距，以及 `0.875rem` 中等字重标题；不要给标题添加遮边背景，也不要叠加 `CardHeader`、额外组标题或第二层同义边框。legend 不参与组内的垂直间距；复杂工具条放在内容容器中，不依赖 legend 参与 flex / grid 排列。保留各字段的 label、独立禁用条件和搜索定位 ID。

设置页相邻的独立设置项统一使用 `.settings-list`，在两项之间绘制消费 `--border` 的 1px 直线，线条与内容左右对齐，不跟随设置项的焦点圆角弯曲。分隔线上下各留 `0.75rem`，首尾由外层容器提供同等留白，不叠加 `space-y`、`divide-y` 或手写分隔符；同一设置的标签、选项和状态保持在一个内容块内。

独立分组用 `data-surface="panel"` 保留阅读保护，面板内分组保持透明；正文、日志、列表和画布使用各自语义结构。容器统一管理间距，保留控件点击范围、长文和画布空间；缩略图按容器增减列数并保留名称与操作。

文本多行编辑统一复用 `ui/textarea`，与 `ui/input` 共用焦点、禁用及 `aria-invalid` 反馈；普通复选框复用 `ui/checkbox`，保留部分选择语义。原生日期、媒体与范围控件通过根 `color-scheme` 和强调色配合明暗主题。

单选下拉框统一复用 `ui/select`，筛选器等普通下拉使用 `SelectContent position="popper"`，不混用浏览器原生 `<select>` 的系统弹层。标题栏悬停说明统一复用 `ui/tooltip` 并从按钮下方弹出；保留 `aria-label`，不要叠加原生 `title` 提示。Tooltip 本体与箭头共用阅读材质；箭头保留原生三角形与单次填色，避免半透明背景重叠产生深色接缝。

同排的单行输入、下拉框和按钮使用相同尺寸档位；默认与紧凑尺寸由共同样式维护，按外框和中心线对齐。触发项、展开选项和输入共用字号与行高 token，Portal 与隔离文档也遵循同一规则。

桌面普通区域屏蔽浏览器默认右键菜单，有实际业务操作时复用项目菜单；保留已有业务菜单的事件处理。文本输入、只读文本、可编辑区域和真实文本选区继续使用 WebView 原生编辑菜单，保留复制、粘贴、撤销和密码框限制。隔离扩展通过 SDK 遵循同一约定，不新增剪贴板权限；浏览器演示保留网页默认行为。

## 说明与布局稳定

安装与授权弹窗以身份摘要、来源和权限分组支持用户判断，各信息说明一次，诊断字段放入可展开详情。安装 / 更新后保留列表和滚动位置，焦点回到原操作区域；升级确认范围见 [安装规则](../extensions.md#安装与体验)。

标题、控件名称和分组表达用途，页面介绍放在主标题下。补充说明仅保留影响判断的信息，长文和多步说明可展开；帮助入口支持悬停、键盘焦点与可访问名称，业务正文、首次使用信息和恢复入口持续可达。

按钮与菜单使用明确动作词，同一操作在宿主与插件中保持一致；上下文已有对象时可写“安装”“更新”“新窗口”。中英文同步精简，保留授权、费用、联网、数据覆盖 / 删除、未保存工作与恢复条件；可访问名称保留区分对象的信息。

默认文案说明任务、结果和数据范围；框架、源码、协议与诊断放入可展开技术资料。新建、保存、备份、导入等主要操作保持可见并统一位置，低频管理放入具名菜单，危险操作继续确认。

收纳说明时移除空容器、固定高度和余留间距，帮助入口紧邻标题或控件。区块间距由外层管理，不叠加同层 gap 与 `space-y-*`。卡片按容器宽度分列、同排操作对齐；同组按钮同尺寸并允许换行；页签按完整项换行或滚动，标签内部不拆字。

路由和扩展加载共用 `page-loading.tsx` 的骨架、边距与稳定滚动槽；隔离界面沿用 SDK 首帧握手，在主题与样式就绪后显示。

placeholder 可提供空输入示例、格式或搜索方向，聚焦时保留、输入后自然消失，不写入真实值，也不代替 Label、可访问名称或持续限制。授权、不可恢复操作、未保存工作、首次阻断错误和字段校验保留紧凑可见说明，进一步解释再展开。

操作反馈使用右下角 toast，扩展通过 SDK `notify` 接入；自动保存成功保持安静。请求完成后不在标题、工具栏和表单间插入横幅或诊断，以免下推控件。首次加载失败、离线或损坏等需持续恢复的情况，在原加载 / 数据区显示紧凑错误和重试；字段错误就近关联并向辅助技术宣告。

持续状态、进度和摘要复用稳定行，长结果使用合理大小的阅读区；省略的文件名、来源和诊断通过键盘可达的详情、Tooltip 或复制提供全文。按改动检查空、加载、成功、失败及长文 / 窄屏 / 大字号，保持当前焦点和相邻控件稳定；用户主动展开、编辑和导航可改变布局。

处理溢出时调整容器和换行，保持正文可达、字号可读。

## 异步数据区的状态

| 状态 | 要求                                                     |
| ---- | -------------------------------------------------------- |
| 空   | 按场景说明原因与下一步动作                               |
| 加载 | 提供可感知的忙碌状态；短请求按需延迟显示骨架屏，避免闪烁 |
| 错误 | 提供可操作的原因与适用的重试 / 恢复入口                  |

当前工程里的 `bridge.tsx` 是参照实现：调用中禁用按钮、成功弹 toast、失败弹 toast 并保留输入。反馈位置、常驻错误和尺寸约束遵循 [说明与布局稳定](#说明与布局稳定)。

交互场景明确标为内置示例或页面内演示，按钮执行可观察的操作，加载演示可取消；数据与反馈如实表达实际能力和作用范围。

## 交互反馈

- 可点击元素保留 hover 与 focus-visible 反馈。
- 不可恢复的删除、清空使用 `variant="destructive"` 并二次确认；页面内演示操作明确说明作用范围并反馈结果。
- 按钮禁用使用 `disabled` 属性；表单错误就近关联字段，需要及时宣告时使用 `role="alert"`。
- HTTP(S) 外链复用 [`ExternalLink`](../../src/components/external-link.tsx)，由链接自身通过原生门面打开系统浏览器，保留链接地址、键盘和中键操作，失败时给出提示；浏览器演示保留标准新标签页行为。全局点击监听仅作为其他链接的兜底。

## 无障碍底线

资源树使用单一 Tab 入口与方向键导航，右键菜单支持 Shift+F10，拖放排序保留按钮替代；可调分隔条提供范围、当前值和方向键操作。

弹窗复用 `DialogContent` 的焦点记录与恢复；业务可用 `onCloseAutoFocus` 指定更合适的相邻项，非模态弹窗保留外部点击目标。触发项删除后沿用可聚焦祖先或主内容回退。关闭按钮消费当前语言；设置搜索取消回到搜索框，选中后保留目标项焦点。

- 图标按钮有可访问名称，键盘焦点清晰可见。
- 状态除颜色外还有文字或图形标识。
- 弹窗与菜单支持键盘操作和 Esc 关闭。
- 内容图片有替代文本，装饰性图片使用 `alt=""`。

## 深色模式检查清单

按改动检查以下明暗主题表现；共享配色变化再覆盖受影响的预设与自定义色：

- [ ] 没有写死的浅色背景或深色文字
- [ ] 边框在深色下仍然可见（用 `border` token，不要 `border-gray-200`）
- [ ] 图标与插图在深色下对比度足够
- [ ] 正文对比度达到 4.5:1，部分选择、禁用和校验状态可辨识
- [ ] 阴影在深色下不会变成"发光的脏块"

## 动效

动效画布可使用局部光晕、轨道与几何造型表达运动；颜色从主题与专用插画 token 派生，文字和操作面板保持语义表面与对比度。高对比度 / 强制颜色模式隐藏非必要光效，不将展示光效扩散为窗口底色。

弹簧、共享布局、指针倾斜、SVG 路径与粒子等动效对应明确的操作或预览语义，并保持内容可读；普通反馈短促，实验与可暂停插画可使用更长时间尺度。

- 应用根部的 `components/demo-motion.tsx` 设置 MotionConfig；持续动画通过 `hooks/use-demo-motion.ts` 观察自己的画布，取得包含应用偏好、系统减少动效、文档可见性和离屏状态的活动策略。
- 连续运动提供明确的暂停 / 继续入口；实验按需提供重播。暂停、场景离屏或文档隐藏时冻结持续运动，恢复后从合理位置继续；卸载时停止播放并释放计时器、观察器、事件和指针捕获。
- MotionConfig 不会自动暂停命令式循环和 SVG 绘制，控制器显式 play / pause / stop；CSS 动画按活动状态切换 `animation-play-state`。
- 减少动效时直接呈现静态结果，输入、选择、布局切换、反馈和信息保持可用。
- 普通过渡优先使用 `transform` 与 `opacity`；共享布局可使用 Motion 的布局能力。控制粒子数、滤镜范围与逐帧更新成本，避免高频 React 状态更新驱动整页重绘。
- 侧栏折叠需要主内容同步重排，保留 240ms 宽度与标签过渡；手动拖宽时禁用过渡。主题圆形裁剪集中在主题 Hook；减少动效时直接切换。
- 主窗口与独立插件窗口共用主题圆形裁剪，从各自主题按钮中心扩散，不复用屏幕坐标；日月图标变换一致。首次恢复、隐藏窗口或应用 / 系统减少动效时直接应用；设置同步与缓存边界见 [外观设置](#外观设置)。
- 指针交互支持触屏、取消捕获和键盘替代；暂停、重播与图标按钮保留可访问名称。

## 代码展示
