# 界面规范

优先使用 `src/index.css` 的 CSS 变量、Tailwind 刻度和现有组件。平台窗口控件等确需固定尺寸时，在对应外壳集中定义。

## 设计基础

- 组件库：shadcn/ui（`radix-nova` 风格），配置在 `components.json`
- 基础样式：`src/styles/shadcn.css`（内置自上游，勿手改；升级方式见文件头注释）
- 字体：默认 Geist Variable；设置页可切到系统字体 / 衬线 / 等宽
- 圆角：`--radius` 变量派生，组件里用 `rounded-md` / `rounded-lg`，不要写 `rounded-[7px]`
- 主题：`next-themes` + `.dark` class；颜色走语义变量，保留用户配色；内置背景沿用皮肤环境色，纯色背景随强调色轻微着色
- 动效：`motion/react` 与 CSS 配合，共用活动与减少动效策略；版本以 `package.json` 和锁文件为准
- 页面层次：共用 `styles/showcase.css`；展厅、组件场景、动效实验室与导航各自维护局部样式

## 外观设置

外观由 `<html>` 的 data 属性驱动，普通组件只消费语义 token。取值、默认值与迁移以 [设置模型](../../src/lib/settings-model.ts) 为准。

| 属性                                            | 作用                                       |
| ----------------------------------------------- | ------------------------------------------ |
| `data-accent`                                   | 强调色，覆盖主色、焦点环、图表和侧栏强调色 |
| `data-radius`                                   | 圆角，改写 `--radius`                      |
| `data-font` / `data-font-size`                  | 字体和根字号                               |
| `data-background` / `data-background-intensity` | 窗口插画、用户图片及装饰强度               |
| `data-motion`                                   | 全局动画与过渡策略                         |

主题在挂载前恢复首屏偏好，运行时由共用 `ThemeEffects` 与 `use-theme-switch` 提交。原生窗口只接受通过 revision 校验的设置快照，缓存用于后续启动，接收结果不再次回写。主窗口与隔离插件共用同步入口；过渡与降级规则见 [动效](#动效)。

**加一个外观项的顺序**：`lib/settings-model.ts` 加类型、默认值、校验与迁移 →
`applySettings` 写 data 属性 → `index.css` 写对应规则 → 设置页加控件。
普通业务组件通过语义 token 绘制。设置页和展厅预设可以读取 / 修改外观设置以实现预览与应用，但不能另建持久化来源；局部预览调色板留在场景 token 内，不提前覆盖整个窗口。

背景在 `lib/backgrounds.ts` 注册，由 `window-background.tsx` 装配、`skin-artwork.tsx` 加载 [皮肤 SVG](../../resources/skins/README.md)。新增时同步映射、风格标识与中英文文案，画廊从注册表生成；展示名称与持久化 ID 分离，旧 ID 保持兼容。纯色模式隐藏装饰并禁用强度控制。本机图片导入保留部分成功项并列出失败文件，晚到结果不覆盖用户新选择，取消背景不删除收藏。存储预算与兼容边界见 [数据存储](../architecture.md#数据存储)，历史取舍见 [ADR 0004](../adr/0004-wallpaper-library.md)。

背景透明度使用 0%–100% 的 11 档滑条，每档 10%，默认 50%。0% 隐藏皮肤并恢复实体表面，100% 完整显示壁纸并让标题栏、侧栏、主体遮罩和普通卡片底色透明。图片与线稿直接跟随滑条，主体保留线性阅读遮罩；普通卡片和磨砂控件按实际叠层补偿中间档位，减少重复盖色，默认档保留正文阅读底色。滑条支持拖动、方向键和 Home / End，显示当前百分比和等距刻度，端点标为“不透明 / 透明”，不额外显示默认值提示。图片原色、控件与弹层的磨砂阅读遮罩、独立设计的插件内容背景继续由各自规则绘制；高对比度模式优先实体表面。

窗口尺寸归原生几何状态，不重复存为主题或布局偏好。预设来自应用配置，标明逻辑像素宽高，选择后立即应用并记忆；工作区不足时适配并提示，其他无效预设禁用并说明原因。界面显示实际尺寸，手动拖动无需匹配预设；失败保留状态与重试入口。浏览器禁用原生尺寸操作，不模拟成功。

启动位置作为持久偏好提供“记住上次位置”和“居中”，默认记住位置；选项保存后在下次创建窗口时生效，当前窗口和重复激活的已有窗口保持原位。恢复默认设置会恢复窗口默认尺寸与记住位置策略，确认框说明作用范围。保存失败时保留确认框和错误。

## 主题插画与轻量资源

内置皮肤使用疏朗手绘线条，SVG 只提供透明蒙版，由 `styles/window-skins.css` 按当前明暗主题和强调色着色，不受系统主题覆盖；用户照片保留原色。暗色不叠加统一绿色色罩、径向光晕、模糊或发光阴影。绘制与体积约束见 [皮肤资源说明](../../resources/skins/README.md)；SVG 不嵌入位图、远端资源或脚本。

- 背景覆盖标题栏、侧栏和主体；内容 surface 按强度调节，默认档位保留阅读底色，输入控件、弹层和关键错误保持清晰。
- 设置页缩略预览和实际背景复用同一绘制源与居中裁剪方式，避免预览另画一份导致效果不一致。
- 装饰层不响应鼠标、不进入无障碍阅读顺序；不加载远端图像、字体或脚本。
- 明暗主题和强调色共用语义 token；高对比度与强制颜色模式优先恢复实体 surface，移除装饰。
- 内置全窗口装饰保持静态；独立插件窗口使用视频封面；主 / 次窗口的用户视频壁纸静音循环，在透明度为 0、减少动效、离屏、文档隐藏或卸载时暂停并显示封面，资源失效时保留封面并提供简短反馈。控制节点数量、滤镜和模糊范围，前景交互插画同样遵循下文的播放与降级约定。

## 标题栏

“视图 → 全屏沉浸”与命令面板、F11 共用命令注册表。进入真实系统 / 浏览器全屏后暂时隐藏标题栏、侧栏及面包屑。指针接近顶部或左缘时，标题栏向下、导航向右滑出并覆盖正文，不推挤内容或改变滚动位置；临时覆盖面板使用对话框阅读底色和局部磨砂，避免与正文叠字，不给正文添加滤镜。离开后延迟收起，栏内焦点、已打开的菜单 / 选择列表及侧栏调宽期间保持展开。边缘入口支持键盘聚焦和 Enter，触屏保留可点击按钮，减少动效时立即切换；窄屏沉浸模式仍可唤出左侧导航。F11、Esc 或唤出标题栏后的退出按钮恢复布局，不改写侧栏偏好，菜单打开时 Esc 优先关闭菜单。系统拒绝或外部退出全屏时，以实际窗口状态为准。原生状态由门面读取并监听窗口变化，浏览器使用 Fullscreen API。

- 高度 40px（`h-10`），自绘：左侧共用 SVG 图标与菜单，隐藏重复的应用名文字；右侧命令面板、语言、主题切换与窗口按钮；语言入口不依赖菜单栏是否显示。系统窗口标题及图标的无障碍名称仍保留。
- 拖拽区域用 `data-tauri-drag-region`，只加在空白容器上；按钮与菜单不要加。
- 窗口按钮只在 Tauri 原生窗口显示；网页直接从应用标题栏开始，不附加演示标记、宣传栏或下载外壳。
- 浏览器窄屏在同一标题栏内显示页面选择器并收起桌面菜单，选择器复用 `APP_ROUTES`，切换同一组真实页面。原生能力的环境限制在对应页面说明。
- macOS 保留系统红绿灯（`tauri.macos.conf.json`），标题栏左侧留 `pl-[78px]` 并隐藏自绘按钮。
- 平台判断统一走 `lib/platform.ts`，不要在组件里解析 UA。

## 颜色：只用语义 token

| Token                                            | 用在哪                                 |
| ------------------------------------------------ | -------------------------------------- |
| `bg-background` / `text-foreground`              | 页面底色与主文字                       |
| `Card` / `.app-surface` / `text-card-foreground` | 随皮肤强度变化的普通卡片与手写面板     |
| `--surface-card-muted`                           | 随皮肤强度变化的次级面板与卡片页脚     |
| `bg-card`                                        | 需要实体底色的表头、绘图内容等局部表面 |
| `bg-muted` / `text-muted-foreground`             | 次级区块（代码块、只读区）、次要文字   |
| `bg-primary` / `text-primary-foreground`         | 主按钮、强调元素                       |
| `bg-destructive`                                 | 删除、不可逆操作                       |
| `text-destructive-foreground`                    | 实心警示背景上的文字或图标             |
| `border` / `border-sidebar-border`               | 分隔线                                 |
| `bg-sidebar` / `text-sidebar-foreground`         | 侧边栏                                 |

**禁止**：

```tsx
// 错误示例：固定颜色无法随深色模式适配
<div className="bg-white text-gray-600 border-gray-200" />
<div className="text-[#333]" />

// 对：语义 token
<div className="app-surface text-muted-foreground border" />
```

主体阅读遮罩独立绘制在 `.window-reading-surface`，不放在滚动主体的背景或子树中，避免控件的背景模糊再次合成祖先底色。遮罩和主体共用 `--app-content-inset`，窄屏、全屏与侧栏调宽沿用同一几何规则。

普通内容容器统一消费 `--surface-card`（`Card` 默认样式或 `.app-surface`）；次级容器使用 `--surface-card-muted`，两者共用皮肤强度曲线。不要在页面里另写固定透明比例，也不要用后代选择器覆盖所有 `bg-card`，以免透明的吸顶表头露出滚动正文。同一外层面板内的分组可保持无底色，避免重复叠层。

输入框、多行编辑、搜索和下拉触发器使用 `--control-background` 与局部背景模糊，不依赖它们位于页面还是 Portal 弹层；禁用底色共用 `--control-disabled-background`，同时保留禁用淡化。运行中暂时锁定的扩展字段保留原底色与文字强度，避免内容闪变。下拉悬停复用 `--control-select-hover-background`。菜单、选择列表、搜索结果浮层与 toast 使用 `--surface-popover`，对话框和命令面板使用 `--surface-dialog`；业务手写控件与浮层分别复用 `.app-control-surface`、`.app-overlay-surface`，不再用局部实体底色覆盖共享控件。

磨砂按已经淡化的窗口背景补偿自身遮罩，卡片在中档同时减轻底色，避免页面、卡片与控件重复盖色。50% 档位下，输入和菜单自身底色约 30%，对话框约 50%；100% 档位下分别保留 65% 和 75% 的阅读遮罩，最终透出的壁纸仍随滑条增加。输入底色沿用 `--popover`，避免深色主题的近黑底色再次压暗；占位文字与浮层弱说明共用 `--glass-muted-foreground`，同时检查明暗主题的极端背景。背景模糊由 0 增至输入 18px、弹层 28px，保证文字、焦点、禁用与选中态可辨。纯色、0% 透明度、高对比度及不支持背景模糊的环境恢复实体底色；不对应用外壳或大面积祖先添加模糊。Tooltip、代码 / 日志阅读区、关键错误、吸顶表头和绘图内容保持实体；次要按钮、标签、开关、复选框及选中 / 悬停色继续按各自状态绘制。图片、图表、画布对象和独立设计的插件背景不强制套用容器透明度。扩展接入规则与跨文档模糊边界见 [SDK 主题与样式](../../sdk/README.md#默认外观与动效)。

图表、主题插画的调色板和无法覆盖的第三方组件可以有专用颜色；将它们集中在对应 token 或绘制规则中，并在 PR 说明。主题插画需同时检查明暗主题与强调色，业务页面继续使用语义 token。

多序列图形使用适配明暗主题、可区分的局部调色板，曲线与图例共用取色入口，并保留名称或序号等文字标识；中性强调色不能抹去序列差异。同组操作保持同高，窄屏换行时仍使用一致尺寸。

## 布局常量

标题栏与侧栏使用视口定位的 `position: fixed`，侧栏导航独立滚动，侧栏顶部和底部操作保持可见。根页面不滚动，右侧 `main` 是标题栏下方的独立原生滚动区；两侧共享 8px 无箭头滚动轨道，离开且不含键盘焦点时延迟淡出，轨道宽度不随显隐改变。菜单打开、长短页面切换不能改变内容宽度或背景构图。外壳祖先不要设置 `transform`、`filter` 等会改变固定定位包含块的属性。桌面与网页均按应用标题栏的实际高度留出内容空间。

滚动、惯性与边界反馈使用浏览器 / WebView 原生行为。主内容和侧栏共用 `.app-scroll-region`，通过 `overscroll-behavior: none contain` 阻止滚动链并保留垂直原生边界效果；减少动效时使用 `none`。应用不添加滚轮 / 触摸回弹监听器、手势计时器或内容位移动画。是否显示回弹、动画幅度及手感由操作系统、输入设备和运行时决定，不为缺少原生回弹的环境模拟动画。

自定义扩展界面使用占满可用区域的独立内容框，右边缘与主内容区齐平，文档自然排版并承担整页滚动；外壳按实际剩余空间设置内容框高度。文档内部滚动槽、默认内边距、字体与作者布局规则统一见 [SDK 默认外观](../../sdk/README.md#默认外观与动效)，避免外壳、文档和普通业务区块叠出多条整页滚动条。

切换页面路径或有效体验导览步骤时只重置内容区滚动，不抢导航焦点或改变侧栏滚动；其他同页查询参数变化保留设置定位行为。偏好与桌面集成共用 `SettingRow`，统一右对齐开关、选择器和操作按钮，窄容器下统一换行。验证时同时检查长页面、短页面、连续双指拖动与松手惯性；自动化滚轮事件不能代替真实触控板的手感验收。

| 区域         | 值                                 | 类名                                                             |
| ------------ | ---------------------------------- | ---------------------------------------------------------------- |
| 标题栏高度   | 40px                               | `h-10`                                                           |
| 页面位置提示 | 随内容滚动，不另设固定标题栏       | `app-route-context`                                              |
| 侧边栏宽度   | 默认 224px，180–360px；折叠 56px   | `settings-model.ts` 定义展开范围，`app-sidebar.tsx` 定义折叠宽度 |
| 内容最大宽度 | 1180px                             | `app-page-content`                                               |
| 内容区内边距 | 按窗口使用 16–28px                 | `styles/app-navigation.css`                                      |
| 卡片之间     | 12px                               | `gap-3`                                                          |
| 页面区块之间 | 业务页 20–24px，展示场景按层次留白 | 共用 studio 与场景样式                                           |

窗口默认最小尺寸 880×600（`tauri.conf.json`）；显示器工作区不足时，原生几何适配会临时降低约束。新增页面要在默认最小尺寸下检查，并确保更小工作区中的主要操作仍可通过滚动到达，不要只在最大化时看效果。

侧栏支持指针和键盘调宽；拖动只预览本窗布局，释放或失去捕获后提交，取消则回退；键盘按操作提交。分隔条保留焦点、范围和值语义，双击或 Enter 恢复默认宽度。折叠导航保留名称与 Tooltip，仅响应当前项悬停或聚焦，一次一条，布局变化后不残留延迟提示或旧退出动画。宽度、折叠与 demo / minimal 模式复用设置模型持久化。

导航按体验、桌面能力、已安装扩展与系统分组。顶部将首个非空组名与折叠按钮放在稳定行，滚动区不重复首组标题；折叠态保留展开按钮、分组语义、间隔和页面提示。底部提供命令面板及平台快捷键，不堆放品牌、版本脚注或装饰指标。页面呈现主标题，外壳保留轻量上下文。

检查 880px 窗口时还要把侧栏拉到 360px；可用内容宽度会继续缩小，场景布局应按容器宽度换行，不能只根据整个窗口的断点选择列数。

## 命令、搜索与恢复

菜单、命令面板和快捷键使用 `providers/commands.tsx` 注册 / 执行入口；命令显示名来自词典，快捷键格式由统一函数生成。新增操作先注册命令，再从各入口引用，避免三个入口行为不同。普通输入、contenteditable、IME、重复按键与快捷键冲突必须按匹配器规则处理。

设置搜索使用 `commands/settings-search.ts` 的索引和稳定控件 ID，在输入框锚定的非模态浮层中显示结果，搜索与空态不推移设置内容。输入期间保持焦点并兼容输入法；选择结果后清空查询、关闭浮层，滚动并聚焦目标。改控件 ID 时同步索引和回归测试；中英文搜索都应可用。

设置保存成功保持安静，不显示常驻成功提示；加载与保存中仅提供不占布局的辅助技术状态。普通保存失败由全局常驻实例维护带重试操作、固定 ID 的右下角 toast，保留修改，恢复后撤回，页面切换不重复插入横幅；检测到未来 schema 时保留紧凑的拒写说明，不能自动覆盖。浏览器预览中的原生页面提供能力说明，不静默伪造成功。

设置按外观、窗口、更新及可折叠的关于与资源组织；隐藏次要信息仍须支持搜索定位，精简模式导览应匹配保留能力。同级字段复用 `SettingLabel` / `SettingRow` 对齐图标、文字与说明；图标使用同尺寸和语义颜色，无图标时不留空位，不在标题和选项重复装饰。

路由渲染失败使用局部恢复边界，保留标题栏、导航与重试 / 回首页入口；应用外壳或根 Provider 渲染失败时由最外层错误边界兜底。事件处理器与异步请求的错误需由调用方处理，不能依赖渲染错误边界捕获；页面数据请求失败不应直接替换整个应用。

## 字号层级

下表像素值以默认 16px 根字号为基准；外观设置会改变 rem 对应的实际尺寸，需在各字号档位检查可读性与溢出。

| 层级       | 字号    | 类名                            |
| ---------- | ------- | ------------------------------- |
| 页面大标题 | 24px    | `text-2xl`                      |
| 区块标题   | 16px    | `text-base`                     |
| 卡片标题   | 14px    | `text-sm font-medium`           |
| 正文       | 14px    | `text-sm`                       |
| 辅助说明   | 12px    | `text-xs text-muted-foreground` |
| 代码       | 12–13px | `font-mono text-xs`             |

业务页以标题、正文、辅助说明组织层级；展厅标题可以随容器放大，但不要靠许多相近字号区分内容。页面大标题上方不重复放置应用名或与面包屑同义的装饰性小标签。默认字号下，正文与关键导航组名不小于 12px；位置提示、刻度等次要信息可以略小，并在不同字号档位检查可读性。

普通状态、错误说明与操作反馈继承当前应用字体；等宽字体用于代码、表达式或需要按列阅读的原始数据，不将整个扩展状态区统一设置为等宽。

## 组件选择顺序

按这个顺序找，找到就停：

1. `src/components/ui/` 里已有的组件
2. 用已有组件组合（不要为了一个布局装新库）
3. `pnpm dlx shadcn@latest add <name>` 新增
4. 自己写——最后才考虑，写完放进 `src/components/<domain>/`

组件库缺少合适语义或交互时可以自建组件，继续复用设计 token、键盘规则与焦点管理。

文本多行编辑统一复用 `ui/textarea`，与 `ui/input` 共用焦点、禁用及 `aria-invalid` 反馈；普通复选框复用 `ui/checkbox`，保留部分选择语义。原生日期、媒体与范围控件通过根 `color-scheme` 和强调色配合明暗主题。

单选下拉框统一复用 `ui/select`，筛选器等普通下拉使用 `SelectContent position="popper"`，不混用浏览器原生 `<select>` 的系统弹层。标题栏悬停说明统一复用 `ui/tooltip` 并从按钮下方弹出；保留 `aria-label`，不要叠加原生 `title` 提示。

桌面普通区域屏蔽浏览器默认右键菜单，有实际业务操作时复用项目菜单；保留已有业务菜单的事件处理。文本输入、只读文本、可编辑区域和真实文本选区继续使用 WebView 原生编辑菜单，保留复制、粘贴、撤销和密码框限制。隔离扩展通过 SDK 遵循同一约定，不新增剪贴板权限；浏览器演示保留网页默认行为。

## 说明与布局稳定

用标题、控件名称和分组表达用途，页面介绍保留为主标题下的可见正文。省去复述操作、实现或显然结果的小字，也不为普通控件重复配帮助图标；只有影响用户判断的补充说明才使用问号帮助，支持悬停与键盘聚焦并具有可访问名称。长文或多步说明由用户展开。业务正文、首次使用信息和恢复入口持续可达。

默认文案说明任务、结果和数据范围；框架、源码、协议与诊断放入可展开技术资料。新建、保存、备份、导入等主要操作保持可见并统一位置，低频管理放入具名菜单，危险操作继续确认。

收纳说明时移除空容器、固定高度和余留间距，帮助入口紧邻标题或控件。区块间距由外层管理，不叠加同层 gap 与 `space-y-*`。卡片按容器宽度分列、同排操作对齐；同组按钮同尺寸并允许换行；页签按完整项换行或滚动，标签内部不拆字。

路由、扩展初始视图及握手等待共用 `page-loading.tsx` 的骨架、边距与稳定滚动槽，不预留巨大画布。隔离界面由 SDK 提交首帧主题和样式后通知宿主显示，再按剩余空间布局；插件不靠定时遮罩或固定等待消除闪白。

placeholder 可提供空输入示例、格式或搜索方向，聚焦时保留、输入后自然消失，不写入真实值，也不代替 Label、可访问名称或持续限制。授权、不可恢复操作、未保存工作、首次阻断错误和字段校验保留紧凑可见说明，进一步解释再展开。

操作反馈使用右下角 toast，扩展通过 SDK `notify` 接入；自动保存成功保持安静。请求完成后不在标题、工具栏和表单间插入横幅或诊断，以免下推控件。首次加载失败、离线或损坏等需持续恢复的情况，在原加载 / 数据区显示紧凑错误和重试；字段错误就近关联并向辅助技术宣告。

持续状态、进度和摘要优先复用标题、标签或工具栏的稳定行，不为未出现的错误空留整行。独立阅读区按实际内容设置合理尺寸，更新不反复挤压控件或拉伸卡片。文件名、来源、状态及诊断长文选择省略、有限行截断或有界阅读区，并通过键盘可达的 Tooltip、详情或复制提供全文。检查空、加载、成功、失败、中英长文、窄屏和大字号下的稳定性；真实正文正常呈现，长结果在已确定区域更新，用户主动展开、编辑与导航可改变布局。

审查时同时检查解释是否必要、完整信息是否可达，以及状态变化是否影响当前焦点和相邻控件位置。不要用绝对定位遮挡正文、无限制减小字号或全局隐藏溢出来掩盖布局问题。

## 异步数据区的状态

| 状态 | 要求                                                     |
| ---- | -------------------------------------------------------- |
| 空   | 说明为什么空 + 下一步动作，不要只写"暂无数据"            |
| 加载 | 提供可感知的忙碌状态；短请求按需延迟显示骨架屏，避免闪烁 |
| 错误 | 说清原因 + 重试按钮，不要吞掉异常                        |

当前工程里的 `bridge.tsx` 是参照实现：调用中禁用按钮、成功弹 toast、失败弹 toast 并保留输入。反馈位置、常驻错误和尺寸约束遵循 [说明与布局稳定](#说明与布局稳定)。

交互场景的数据明确标为内置示例或页面内演示。每个按钮都应改变状态、打开真实浮层或提供有用反馈；加载演示可取消。不要放置无操作按钮、伪造的构建健康度、测试统计或包大小，示例协作者与通知也不能暗示已发送邮件、修改账户或写入原生数据库。

## 交互反馈

- 可点击元素必须有 hover 与 focus-visible 反馈，只在 hover 上做反馈会让键盘用户迷路。
- 不可恢复的删除、清空使用 `variant="destructive"` 并二次确认；页面内演示操作明确说明作用范围并反馈结果。
- 按钮禁用时用 `disabled` 属性，不要用 `pointer-events-none` 假装禁用（屏幕阅读器读不到）。
- 表单校验错误显示在字段下方，`text-xs`，不要调用 `window.alert`；`role="alert"` 可用于需要及时宣告的错误文本。
- HTTP(S) 外链复用 [`ExternalLink`](../../src/components/external-link.tsx)，由链接自身通过原生门面打开系统浏览器，保留链接地址、键盘和中键操作，失败时给出提示；浏览器演示保留标准新标签页行为。全局点击监听仅作为其他链接的兜底。

## 无障碍底线

资源树使用单一 Tab 入口与方向键导航，右键菜单同时支持 Shift+F10；拖放排序保留按钮替代。可调分隔条提供范围、当前值和方向键操作。没有 `DialogTrigger` 的受控弹窗显式记录并恢复触发项焦点，不能关闭后落到页面根部。

共用 `DialogContent` 在打开时记录当前操作位置，模态弹窗关闭时恢复焦点；业务传入的 `onCloseAutoFocus` 优先，非模态弹窗保留外部点击目标。触发项删除后回到仍存在的可聚焦祖先或主内容区；有更合适的相邻项时由业务指定。关闭按钮默认消费当前语言，仍可用 `closeLabel` 覆盖。设置搜索取消回到搜索框，选中结果则保留目标设置项焦点。

- 只有图标的按钮必须有 `aria-label`，例如主题切换按钮。
- 不要移除焦点环；需要美化就换颜色，不要 `outline: none`。
- 颜色不能是唯一的信息载体（成功/失败要同时有图标或文字）。
- 弹窗、下拉菜单要能用键盘操作，Esc 能关。
- 图片有 `alt`，装饰性图片用 `alt=""`。

## 深色模式检查清单

新增或修改页面时，检查深色模式下的以下行为：

- [ ] 没有写死的浅色背景或深色文字
- [ ] 边框在深色下仍然可见（用 `border` token，不要 `border-gray-200`）
- [ ] 图标与插图在深色下对比度足够
- [ ] 七种强调色的主按钮在正常及悬停时，正文对比度达到 4.5:1；部分选择、禁用和校验状态可辨识
- [ ] 阴影在深色下不会变成"发光的脏块"

## 动效

动效画布可使用局部光晕、轨道与几何造型表达运动；颜色从主题与专用插画 token 派生，文字和操作面板保持语义表面与对比度。高对比度 / 强制颜色模式隐藏非必要光效，不将展示光效扩散为窗口底色。

当前演示允许弹簧、共享布局、指针倾斜、SVG 路径与粒子等动效，运动应对应明确的操作或预览语义，并保持内容可读。普通反馈通常约 150ms、页面过渡约 300ms；动效实验与可暂停的前景插画可使用更长的时间尺度。

- 应用根部的 `components/demo-motion.tsx` 设置 MotionConfig；场景通过 `hooks/use-demo-motion.ts` 结合应用偏好、系统 `prefers-reduced-motion`、文档可见性与 IntersectionObserver 取得活动状态。持续动画应观察自己的画布，不能仅观察仍有其他内容可见的长页面。
- 连续运动提供明确的暂停 / 继续入口；实验按需提供重播。暂停、场景离屏或文档隐藏时冻结持续运动，恢复后从合理位置继续；卸载时停止播放并释放计时器、观察器、事件和指针捕获。
- MotionConfig 不会自动暂停命令式循环和 SVG 绘制；相关控制器需显式 play / pause / stop，CSS 动画使用活动状态切换 `animation-play-state`。不要只隐藏画面却继续运行后台循环。
- 应用选择减少动效或系统请求减少动态效果时，取消位移、旋转、视差和循环，直接呈现静态结果；输入、选择、布局切换、反馈和信息仍可用。不能要求用户先开启动画才使用功能。
- 普通过渡优先使用 `transform` 与 `opacity`；共享布局可使用 Motion 的布局能力。控制粒子数、滤镜范围与逐帧更新成本，避免高频 React 状态更新驱动整页重绘。
- 侧栏折叠需要主内容同步重排，保留 240ms 宽度与标签过渡；手动拖宽时禁用过渡。主题圆形裁剪集中在主题 Hook；减少动效时直接切换。
- 主窗口与独立插件窗口共用主题圆形裁剪，从各自主题按钮中心扩散，不复用屏幕坐标；日月图标变换一致。首次恢复、隐藏窗口或应用 / 系统减少动效时直接应用；设置同步与缓存边界见 [外观设置](#外观设置)。
- 指针交互同时考虑触屏、取消捕获和键盘替代。暂停、重播及纯图标按钮有可访问名称；无障碍用户不能只能看到装饰而无法操作场景。

## 代码展示

代码统一复用 `components/code-block.tsx`，必须显式指定语言：JSON、Rust、TypeScript 分别使用 `language="json"`、`language="rust"`、`language="typescript"`，未知语言使用 `language="text"` 保持纯文本。混合语言的教程按语言拆成独立代码块，不用一个语言解析整段示例。能力目录、IPC 示例、网络响应和后台程序的 JSON 输出均遵守此约定；普通笔记和 URL 不作为源码着色。

工作台按 `.rs` 和 `.ts` / `.mts` / `.cts` 后缀识别；Markdown 围栏共用 [语言归一化规则](../../src/lib/code-language.ts)，未声明或未支持的语言保持纯文本。依赖与懒加载边界见 [模块指南](../demo-modules.md#依赖与加载)。高亮覆盖明暗与强制颜色模式，保留空格、选择和复制结果；用户内容以 React 文本渲染，不注入 HTML。Rust 与 TypeScript 有界着色，超出限额的文本完整保留。
