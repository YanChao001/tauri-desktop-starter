# 内置图片壁纸

此目录保存随软件发布的图片原件，与[矢量皮肤](../skins/README.md)及用户导入的“我的壁纸”图库分开维护。

## 新增与排序

1. 将 JPEG、PNG 或 WebP 图片放入本目录，可使用子目录；支持 `.jpg`、`.jpeg`、`.png`、`.webp` 及其全大写扩展名。图片应先离线优化，构建保留原始分辨率与文件字节。
2. 推荐使用 `001-名称.jpg`、`002-名称.webp` 等文件名排序。应用按相对路径的字符顺序排列，显示名称会去掉数字排序前缀与扩展名；首张图片是首次使用和恢复默认设置时的默认壁纸。目录没有图片时使用纯色。
3. 正常运行开发或构建命令即可，无需注册清单或修改源码。增删文件后，已运行的开发服务器可能需要重启；正式构建会重新收录当前全部图片。

[资源清单](../../src/lib/bundled-wallpapers.ts)通过 Vite glob 导入图片，桌面和网页构建均自动生成带内容哈希的资源地址，支持网页子路径部署。桌面安装版与便携版从前端资源中携带这些图片，无需另行复制到 Tauri 的额外资源目录，也不依赖开发机上的原始文件路径。

## 设置与维护

设置只保存 `bundled:相对文件名`，不保存构建哈希地址、绝对路径或图片 data URL。替换同名文件可以更新图片而保留选择；改名会改变身份，删除或改名后的旧选择回落到当前默认壁纸。已有合法的皮肤和自定义图片偏好继续保留。

内置图片排在设置页皮肤网格的前面，共用背景透明度；用户可切换纯色、矢量皮肤或自己的图片。缩略图与用户图库复用按显示尺寸、屏幕像素密度平滑采样的预览组件，窗口背景继续加载完整原图。内置文件不写入用户图库，不计入其容量，运行时不提供重命名或删除操作。

当前 `001-秋日花饰少女.jpg` 由提供的 3840 × 2160 JPEG 做 DCT 无损优化并转换为渐进扫描，保留元数据。文件为 1,193,129 字节，比原图减少约 6.4%；未缩放、裁切或重新量化，解码像素与原图一致。
